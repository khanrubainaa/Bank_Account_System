
# Bank Account System (OOP)

## About
This project is a simple Bank Account System developed using Python and Object-Oriented Programming.

It allows users to deposit money, withdraw money and check their account balance.

## Features
- Create bank accounts for different users.
- Deposit money into an account.
- Withdraw money from an account.
- Display the current account balance.
- Prevent withdrawals when the balance is insufficient.
- Prevent negative account balances.

## Concepts Used
- Classes and Objects
- Constructors (__init__)
- Methods
- Variables and Conditional Statements
- F-strings

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the command:

   python bank_account.py

## Project Language
Python
